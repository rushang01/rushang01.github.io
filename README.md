# Rushang Chiplunkar's portfolio

A static site built with [Astro](https://astro.build). Projects live in one content file each.

```bash
npm install
npm run dev     # local site at http://localhost:4321
npm run build   # checks content, then builds to dist/
```

- **Add a project:** see [HOW_TO_ADD_A_PROJECT.md](HOW_TO_ADD_A_PROJECT.md)
- **Design rules:** see [DESIGN.md](DESIGN.md)
- **Deployment:** merging to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`. A private repo never deploys.
